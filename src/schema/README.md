# Schema tables

Data derived from the Kubernetes OpenAPI schema that kustomize embeds.

| File | What | Upstream |
|---|---|---|
| `namespace-scope.json` | whether each built-in kind is namespaced (cluster-scoped kinds have no namespace in their id) | `kyaml/openapi/openapi.go` `precomputedIsNamespaceScoped` |
| `smp-schema.json` | every definition's fields with their patch strategy and merge keys, for strategic merge patch | kyaml's embedded Kubernetes schema (`kyaml/openapi/kubernetesapi`, v1.21.2) |

  descriptions and validation.
